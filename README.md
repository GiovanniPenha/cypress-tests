# Cypress — Testes Automatizados E2E

Projeto de estudos desenvolvido durante o curso de **QA da Alura**, com o objetivo de aprender e praticar automação de testes utilizando Cypress.

## Sobre o projeto

O projeto utiliza a aplicação web Adopet para praticar testes automatizados end-to-end (E2E), simulando interações de um usuário com a interface.

O desenvolvimento faz parte da minha jornada de aprendizado em Quality Assurance (QA), com foco nos fundamentos de automação de testes.

## Tecnologias utilizadas

- **Cypress 13.6.4** — automação de testes E2E
- **JavaScript** — linguagem utilizada nos testes
- **Node.js e npm** — ambiente e gerenciamento de dependências
- **Git e GitHub** — versionamento e publicação do projeto

## Cenários em estudo

- Acesso à aplicação Adopet
- Interação com a tela de cadastro
- Preenchimento dos campos do formulário
- Envio do formulário e análise do comportamento da aplicação

Os cenários e as validações serão ampliados conforme o avanço nos estudos.

## Como executar o projeto

**Pré-requisitos:** Node.js e npm instalados.

1. Clone este repositório:

   ```bash
   git clone https://github.com/GiovanniPenha/cypress-tests.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd cypress-tests
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Abra a interface do Cypress:

   ```bash
   npx cypress open
   ```

5. Selecione **E2E Testing**, escolha um navegador disponível e execute o teste.

Para executar os testes em modo headless pelo terminal:

```bash
npx cypress run
```
